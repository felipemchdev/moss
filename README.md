# Moss

Browser minimalista e dark-first construído com [Tauri 2](https://tauri.app) (Rust + TypeScript).

## Desenvolvimento

Pré-requisitos: Node, pnpm, Rust (rustup) e os [pré-requisitos do Tauri](https://tauri.app/start/prerequisites/) para o seu sistema.

```sh
pnpm install
pnpm tauri dev
```

Veja `AGENTS.md` para o workflow do time e as convenções.
